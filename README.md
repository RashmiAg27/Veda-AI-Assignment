# Veda-AI-Assignment

VedaAI is a full-stack AI-powered assessment creator for Indian schools. Teachers can define question types, upload reference material, and receive a fully formatted question paper — complete with an answer key — generated by Claude AI.

---

## Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                         Browser (Next.js)                        │
│  /assignments  /create  /output/[id]                            │
│  Zustand store  ←  socket.io-client  ←  WebSocket              │
└────────────────────────────┬────────────────────────────────────┘
                             │ REST + WebSocket
┌────────────────────────────▼────────────────────────────────────┐
│                    Express API (Node.js)                         │
│  POST /api/assignments  →  BullMQ queue                         │
│  GET  /api/papers/:id   ←  Redis cache (TTL 3600s)             │
│  POST /api/papers/:id/pdf  →  Puppeteer PDF                     │
└──────────┬──────────────────────────────────┬───────────────────┘
           │                                  │
┌──────────▼──────────┐             ┌─────────▼─────────┐
│   MongoDB (Mongoose) │             │  Redis + BullMQ   │
│  Assignment          │             │  paper-generation │
│  GeneratedPaper      │             │  queue            │
└─────────────────────┘             └─────────┬─────────┘
                                              │
                                    ┌─────────▼─────────┐
                                    │  BullMQ Worker     │
                                    │  → Anthropic API   │
                                    │  → Save to MongoDB │
                                    │  → Cache in Redis  │
                                    │  → Emit via socket │
                                    └───────────────────┘
```

## Prerequisites

- Node.js 18+
- MongoDB (local or Atlas)

## Setup

### 1. Clone and install

```bash
git clone <repo-url>
cd vedaai

# Backend
cd backend
npm install
cp .env.example .env
# Edit .env with your credentials

# Frontend
cd ../frontend
npm install
cp .env.local.example .env.local
# Edit .env.local if backend isn't on localhost:4000
```

### 2. Start MongoDB and Redis

```bash
# MongoDB (local)
mongod --dbpath /data/db

# Redis (local)
redis-server
```

### 3. Run development servers

```bash
# Backend (from backend/)
npm run dev

# Frontend (from frontend/)
npm run dev
```

Frontend: http://localhost:3000  
Backend API: http://localhost:4000

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/assignments` | List all assignments |
| `POST` | `/api/assignments` | Create assignment + enqueue AI job |
| `GET` | `/api/assignments/:id` | Get single assignment |
| `DELETE` | `/api/assignments/:id` | Delete assignment + paper |
| `GET` | `/api/papers/:assignmentId` | Get generated paper (cached) |
| `POST` | `/api/papers/:assignmentId/pdf` | Generate and download PDF |
| `GET` | `/health` | Health check |

## Generation Flow

```
1. Teacher fills Create Assignment form
2. POST /api/assignments → saved as status: "pending"
3. BullMQ job enqueued with assignmentId
4. Frontend connects WebSocket, joins room = assignmentId
5. Worker picks up job:
   a. status → "processing", emits job:progress via socket
   b. Calls Anthropic claude-sonnet-4-20250514 with structured prompt
   c. Parses JSON response → validates sections non-empty
   d. Saves GeneratedPaper to MongoDB
   e. Caches paper in Redis (key: "paper:{assignmentId}", TTL 3600s)
   f. status → "completed", emits job:complete with paperId
6. Frontend receives job:complete, fetches paper, navigates to /output/[id]
7. Teacher can download as PDF (Puppeteer A4 render)
```
